## 🛠️ قسم الإدارة (Admin)

الأوامر:
- `/admin` فتح لوحة الإدارة بالأزرار.
- `/userinfo <user_id|@username>` شاشة معلومات لمستخدم مع أزرار سريعة (تمديد 7 أيام/إلغاء).
- `/activate <user_id|@username> <plan_code> [days]` تفعيل اشتراك يدوي مع مدة مخصصة اختيارية.
- `/extend <user_id|@username> <extra_days>` تمديد مدة اشتراك مستخدم نشط.
- `/revoke <user_id|@username>` إلغاء اشتراك مستخدم وإرجاعه للوضع المجاني.
- `/broadcast <message>` إرسال رسالة لكل المستخدمين.
- `/users` عرض أول 20 مستخدم.

الطلبات المعلقة:
- كل طلب يحتوي زر "✅ موافقة" وزر "⛔ إلغاء" للتصرف السريع.

تذكيرات الانتهاء:
- تذكير تلقائي قبل 48 ساعة من انتهاء الاشتراك.
- تذكير أخير قبل 24 ساعة.

تشغيل آمن:
- حذف أي Webhook عند البدء لتفادي التعارض.
- حارس مثيل واحد عبر ملف `bot.lock` لمنع تشغيل أكثر من نسخة.

تقرير أسبوعي:
- إرسال تقرير مختصر للأدمن كل يوم أحد صباحاً يحتوي على إجمالي المستخدمين والأسئلة ونشاط الاشتراكات.
